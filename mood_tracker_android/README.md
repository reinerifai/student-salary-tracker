# Daily Mood Tracker (Android)

One-activity Android app (Java) — Dark mode neon style.
- No database
- Single Activity
- Package: com.example.moodtracker

## How to open
1. Download and unzip the project.
2. Open Android Studio -> File -> Open -> select the project folder.
3. Let Android Studio sync Gradle (it may prompt to update Gradle or the Android Gradle Plugin).
4. Run on an emulator or real device (minSdk 21).

## Files included
- app/src/main/java/com/example/moodtracker/MainActivity.java
- app/src/main/res/layout/activity_main.xml
- app/src/main/AndroidManifest.xml
- build.gradle (top-level) and app/build.gradle

## Notes
This is a simple project skeleton intended for classroom submission. If Android Studio complains about Gradle versions, you can update the Gradle plugin and wrapper via Android Studio's suggestions.
